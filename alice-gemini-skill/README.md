# Alice + Gemini Skill (Интеграция Алисы с Gemini)

Готовый к развертыванию приватный навык для голосового помощника **Яндекс Алиса** (Яндекс.Диалоги), подключенный к моделям **Google Gemini** через современный официальный SDK `google-genai`.

---

## Архитектура решения

```
Пользователь → Алиса → HTTPS Webhook (/webhook) → FastAPI/aliceio → Gemini API (google-genai) → Ответ → Алиса
```

### Ключевые особенности
- **Соблюдение жесткого SLA Алисы**: Встроен таймаут на обращение к Gemini (2.5 сек) и общий предохранитель вебхука (2.9 сек).
- **Специализированный System Prompt**: Модель настроена отвечать без markdown, кратко (до 600 символов для комфортного озвучивания Алисой), а на запросы кода выдавать чистый код.
- **Поддержка контекста**: Хранение истории диалога (до 3 последних реплик пользователя) в памяти.
- **Два режима работы**: Локальный сервер / VPS на FastAPI (`uvicorn`) и бессерверный деплой в **Yandex Cloud Functions** (`main.handler`).

---

## 1. Получение API-ключа Gemini

1. Перейдите в [Google AI Studio](https://aistudio.google.com/).
2. Авторизуйтесь с вашим Google-аккаунтом.
3. Нажмите **Get API key** → **Create API key**.
4. Скопируйте полученный ключ.

---

## 2. Локальный запуск и настройка

### Шаг 2.1. Клонирование и переход в каталог
```bash
cd alice-gemini-skill
```

### Шаг 2.2. Создание виртуального окружения (Python 3.12+)
```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
```

### Шаг 2.3. Настройка переменных окружения
Скопируйте шаблон `.env.example`:
```bash
cp .env.example .env
```

Отредактируйте `.env`:
```ini
GEMINI_API_KEY=ваш_ключ_google_ai_studio
GEMINI_MODEL=gemini-2.5-flash
TEMPERATURE=0.3
MAX_OUTPUT_TOKENS=800
MAX_RESPONSE_LENGTH=600
GEMINI_TIMEOUT_SECONDS=2.5
PORT=8000
```

### Шаг 2.4. Запуск сервера
```bash
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

Сервер будет доступен по адресу: `http://localhost:8000`  
Проверка статуса: `http://localhost:8000/ping`

## 3. Локальное тестирование вебхука через ngrok

Для подключения к Яндекс.Диалогам требуется публичный HTTPS-URL.

1. Запустите туннель:
```bash
ngrok http 8000
```
2. Скопируйте полученный публичный URL вида:
```
https://xxxx-xx-xx-xx.ngrok-free.app
```
3. Ваш Webhook URL для Алисы:
```
https://xxxx-xx-xx-xx.ngrok-free.app/webhook
```

## 4. Настройка навыка в консоли Яндекс.Диалогов

1. Перейдите в [Яндекс Диалоги](https://dialogs.yandex.ru/developer).
2. Нажмите **Создать диалог** → выберите **Навык в Алисе**.
3. Заполните основные поля:
   - **Имя навыка**: `Мой Gemini` (или любое желаемое).
   - **Тип доступа**: Выберите **«Приватный»** (не требует модерации Яндекса, доступен сразу только вам и тем, кому вы дадите доступ).
   - **Backend**: Выберите **Webhook URL** и вставьте URL:
     - Для локального теста через ngrok: `https://xxxx-xx-xx-xx.ngrok-free.app/webhook`
     - Для Yandex Cloud Functions: URL вашей функции.
4. Сохраните настройки.
5. Перейдите на вкладку **«Тестирование»**:
   - Начните диалог (отправьте любое сообщение или запустите сессию).
   - Навык поприветствует вас:  
     *«Привет! Я подключена к Gemini. Спроси меня о чём угодно, включая код»*.
   - Задайте вопрос: например, *«напиши функцию быстрой сортировки на python»*.
   - Убедитесь, что навык возвращает корректный ответ за < 3 секунд.

## 5. Production деплой в Yandex Cloud Functions

1. Подготовьте ZIP-архив с файлами проекта:
```bash
cd alice-gemini-skill
zip -r skill.zip main.py config.py gemini_client.py requirements.txt
```
2. Перейдите в консоль [Yandex Cloud](https://console.yandex.cloud/) → выберите каталог.
3. Откройте сервис **Cloud Functions** → нажмите **Создать функцию**:
   - Название: `alice-gemini-skill`.
4. В редакторе функции:
   - **Среда выполнения**: `Python 3.12`.
   - **Способ**: Загрузка ZIP-архива (загрузите `skill.zip`).
   - **Точка входа**: `main.handler`.
   - **Таймаут**: `3` сек.
   - **Память**: `256` МБ (или 512 МБ).
5. В разделе **Переменные окружения** добавьте:
   - `GEMINI_API_KEY`: значение вашего API-ключа.
   - `GEMINI_MODEL`: `gemini-2.5-flash` (или `gemini-3.8-flash`).
6. Сохраните и сделайте функцию **публичной** (флаг «Публичная функция»).
7. Скопируйте полученную ссылку на вызов функции и укажите её в настройках навыка в Яндекс.Диалогах.

---

## 6. Запуск тестов

Для запуска автоматических тестов:
```bash
pytest
```

Все тесты проверяют:
- Обработку новой сессии и приветствия Алисы.
- Работу эндпоинта `/webhook` с моком ответов Gemini.
- Защиту от таймаута: возврат фразы-заглушки при медленном ответе Gemini.
- Прямую совместимость с точкой входа `handler` для Yandex Cloud Functions.
